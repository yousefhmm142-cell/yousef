# صفحة الدخول — 17 نوفمبر 2026

- صفحة RTL مبسطة بنفس ألوان النظام والخط والشعار الأصلي، واسم النظام والشركة وفوتر بسيط.
- رسم SVG داخل موضع الشعار بالتزامن مع عرض الصفحة كاملة؛ لا شاشة مقدمة أو تعطيل للنموذج. بعد نحو 1.55 ثانية يظهر الأصل وتختفي الحدود. تفضيل تقليل الحركة يعرض الأصل مباشرة.
- لا مكتبة أو خط جديد، ولا تغيير لدوال المصادقة أو مكوّن الرمز أو حفظ الجلسة. زيادة البناء المضغوط الإجمالية مقارنة ببناء اختيار مهام الأختام السابق نحو 1.9KB.

## ما جُرّب

- TypeScript ناجح. ESLint: صفر أخطاء، 3 تحذيرات سابقة بملفات أخرى.
- Vitest: 154 ناجحًا، 3 متجاوزة لغياب ملفات Excel الأصلية. البناء ناجح.
- Chromium ببيانات وقاعدة تجريبية محلية: فاتح وليلي، بعروض 320 و390 و1366، دون تمرير أفقي؛ حجم نص 20px بعرض 320. صور محفوظة أثناء الرسم وبعده.
- الحقول ظاهرة وقابلة للكتابة أثناء تغيّر strokeDashoffset، ولا قناع يحجبها. الجوال المحفوظ يوجّه التركيز للرمز فورًا، وتقليل الحركة يفتح النموذج بالشعار الكامل.
- دخول خاطئ يُظهر الخطأ ويصفّر الرمز. اكتمال الست خانات يرسل طلب مصادقة واحدًا، ودخول صحيح ثم تنقل وإعادة تحميل يحتفظان بالجلسة.
- لا أخطاء JavaScript في السيناريوهات، ولا تحذيرات console عند فتح صفحة الدخول وحدها. سيناريو بيانات الدخول الخاطئة يتضمن طلب مصادقة مرفوضًا متوقعًا.

## ما لم يُجرّب

- جوال حقيقي، Safari حقيقي أو تطبيق Android.
- حسابات أو بيانات الإنتاج. لا تغيير بقاعدة البيانات لهذا التعديل.
