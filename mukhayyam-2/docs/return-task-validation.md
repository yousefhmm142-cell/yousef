# إرجاع المهمة لانتظار فني

الزر بجانب «تحويل لفني آخر» على المهام المسندة الجديدة/المرسلة/المفتوحة من الفني (new/sent/seen)، بنفس الألوان. عند تأكيد الإرجاع يُزال تعيين جميع الفنيين وتظهر المهمة في «بانتظار فني» بنفس الرقم والبيانات، دون نسخ أو إرسال رسائل. تبقى حالات بدأت/منجزة/ملغاة محمية بقواعد الخادم. إشعار النجاح يتيح فتح قائمة الانتظار دون نقل المستخدم عنها تلقائيًا أثناء إرجاع عدة مهام.

لا تعديل مخطط أو صلاحيات: استُخدم runOrQueue وتحديث حقلي التعيين فقط، والخادم القائم يعيد الحالة إلى new ويمسح sent_at/seen_at. باقي الحقول لا تُرسل أصلًا، لتفادي الكتابة فوق تعديل أحدث. المحلي والطابور يعكسان الإرجاع بلا نت ثم يتزامنان، والفردية والمشتركة بنفس المسار.

التحقق: الأنواع والبناء ناجحان، 163 اختبارًا ناجحًا و3 اختبارات Excel متجاوزة، ESLint بلا أخطاء مع 3 تحذيرات قائمة. Chromium محلي فاتح/ليلي ×320/390/1366، الزران بلا تداخل أو خروج الصفحة. إلغاء التأكيد لم يغير شيئًا. حساب staff يملك صفحة المهام دون دور مدير أعاد مهمة مرسلة ومشتركة مع بقاء الرقم والنوع والمشترك والتفاصيل والمكان والأولوية والمدة وتاريخ الإنشاء والرابط وسائر الحقول، باستثناء حقول التعيين والحالة والإرسال/الاطلاع والتحديث المقصودة. الإرجاع بلا نت فوري، ثم تزامن ومسح جميع المشاركين. الحالات بدأت/منجزة لا تظهر الزر، ومحاولات مباشرة للخادم رفضت إرجاعها دون تغيير بياناتها.
