# اختيار مهمة عند استخدام ختم — 17 نوفمبر 2026

أزيل البحث المنفصل «رقم المهمة أو اسم المشترك» وقائمة المتصفح الأصلية. الاختيار داخل نموذج الختم بقائمة بطاقات محدودة الارتفاع، تبين اسم صاحب الختم ورقم المهمة والعمل والمشترك والتاريخ والطبلون. تعمل بالكيبورد وتغلق باختيار المهمة أو Escape أو النقر خارجها.

المهام منجزة ومخصصة لصاحب الختم بمعرّفه، بما فيها المهمة المشتركة التي يشارك بها. لا صلاحية جديدة للمحاسبة على جدول المهام الخام، ولا عرض توكنات أو هواتف. تظل القائمة آخر 100 مهمة كما كانت، مع ظهور الربط المحفوظ أولًا. الربط التلقائي والتسجيل اليدوي باقٍ عند عدم اختيار مهمة.
