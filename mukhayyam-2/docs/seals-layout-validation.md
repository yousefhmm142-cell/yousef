# ترتيب الأختام وتهدئة الوضع الليلي

- عناوين واضحة وموحّدة لكل صف في مجموعات السجل، ومحاذاة أرقام الأختام والحالات والتواريخ والتفاصيل. عنوان الدفعة منفصل عن البيانات؛ التاريخ دون تكسير.
- الموبايل بصفين منظمين، وشارة المهمة أسفل رقم الختم. الجدول له تمرير داخلي وإشارة للسحب عند الحاجة؛ خيارات الفرز الموسعة تلتف داخل الشاشة.
- مساحة الأختام بالليلي صلبة وأهدأ، دون blur أو تراكب شفافية البطاقات. التخصيص مربوط بمسار الأختام؛ لم تتغير ألوان حالات الختم أو البيانات أو وظائف الحفظ.

التحقق: TypeScript والبناء ناجحان، ESLint صفر أخطاء و3 تحذيرات سابقة، و157 اختبارًا ناجحًا و3 اختبارات Excel متجاوزة لغياب الملفات. Chromium بقاعدة تجريبية: الصفحات الأربع، فاتح وليلي، عروض 320 و390 و1366. بعد معالجة الفرز الموسع والجدول، أُعيد فحص المجموعات والجدول على المقاسات الستة: لا خروج أفقي، أعمدة موحدة، خلفية الليلي صلبة، فتح نموذج الختم من الصف والمجموعات والجدول دون خطأ JavaScript. فُحص فتح التعديل والسجل وتأكيد الحذف ثم إلغاؤه واستدعاء الطباعة دون حذف فعلي، وتباين أزرار الدفعات بالليلي 10.55:1.

لم تُجرّب طابعة ورقية أو جوال حقيقي أو بيانات الإنتاج. لا تعديل لقاعدة البيانات.
