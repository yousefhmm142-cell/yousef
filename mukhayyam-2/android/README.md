# تطبيق الأندرويد (APK)

نافذة كاملة على موقع النظام (Android WebView، بدون أي مكتبات خارجية: ملف ~160 كيلوبايت). كل ما يظهر فيه يأتي من الموقع، فتحديثات الموقع تصل للتطبيق وحدها؛ لا يُعاد بناء هذا التطبيق إلا إذا تغيّر عنوان الموقع (`siteUrl` في `app/build.gradle`).

- يُحمَّل من: `https://mukhayyam2.pages.dev/mukhayyam2.apk`
- ليفتح بلا شريط عنوان، يحتاج الموقع الملف `/.well-known/assetlinks.json` (في `app/public/`) ببصمة مفتاح التوقيع.
- مفتاح التوقيع **ليس** في المستودع. احفظ ملف `mukhayyam2.keystore` وكلمة سره عندك: بدونهما لا يمكن إصدار تحديث يُثبَّت فوق النسخة الحالية.

البناء (يحتاج Android SDK وJava 17+):

```bash
M2_KEYSTORE=/path/mukhayyam2.keystore M2_KEYSTORE_PASSWORD=... ANDROID_HOME=/path/android-sdk gradle -p android assembleRelease
```

الناتج: `android/app/build/outputs/apk/release/app-release.apk`

## ما يعمله التطبيق (الإصدار 2.0)
- يفتح الموقع بنافذة كاملة، ويبقى النظام يعمل بدون إنترنت بعد أول فتح (الموقع نفسه يحفظ نفسه وكشوف اليوم على الجهاز).
- روابط الموقع (رابط مهمة الفني، ورقة الحضور) تفتح داخله. أي رابط آخر (واتساب، اتصال، SMS) يفتح بالتطبيق المخصص له.
- اختيار ملف (استيراد Excel) وحفظ الملفات (تصدير Excel والنسخ الاحتياطي) والطباعة تعمل من داخله.
- إن تعذّر تشغيل محرك الويب على الجوال يفتح الموقع بالمتصفح بدل أن يُغلق التطبيق.
- اختبارات آلية (Robolectric) تشغّل التطبيق على أندرويد 7 و9 و13 و14: `gradle -p android :app:testDebugUnitTest`.
